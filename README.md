# Dropshipping Product Winning Score Analyzer

A React-based web application that evaluates whether a dropshipping product has the potential to become a winning product using a rule-based scoring system.

The application analyzes products using 13 evaluation criteria along with Google Trends score and active advertisement count to generate a final score out of 100.

---

# Features

* Product evaluation using 13 rules
* Google Trends and active ads analysis
* Final product score and verdict
* Result dashboard with progress visualization
* Product history tracking using LocalStorage
* Responsive modern UI using React

---

# Scoring Categories

Products are classified as:

```text id="n6umwd"
75+   → Winning Product
50-74 → Average Product
Below 50 → Weak Product
```
